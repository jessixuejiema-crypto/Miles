Life Rule-Space Map

Every cell of this graph is one Life-like rule B…/S… — y axis = Birth set, x axis = Survive set. Each rule is actually simulated from the same random soup and classified: unstable rules blob out toward infinity, stable rules keep transforming but settle without exploding (Conway's B3/S2-3 lives here), and the rest quickly disappear to nothing or a few little oscillators. The main view uses contiguous dash-ranges like 3-7 or 6-7; the arrows switch each axis to the split sets, shifting the gap by one — first tab 3,5-7, second tab 3,6-7. Click any cell to watch that rule run below. Full simulator: conway.html.

Method: each rule runs up to 320 generations on a bounded 36×36 grid seeded with the same 30% random soup. If almost nothing is left it dies; if it stays dense or keeps churning — or freezes only after filling the box — it is unstable (on an infinite grid the blob would grow forever); if it settles into still lifes and small oscillators at low density it is stable. Axis labels mark where each set's first number starts; hover any cell for the exact rule.
