Life Rule-Space Map

Every cell of this graph is one Life-like rule B…/S… — y axis = Birth set, x axis = Survive set. Each rule is actually simulated from small random soups and sorted into five states: unstable rules spread until they cover half the world, stable rules slowly transform into oscillators and stay bounded (Conway's B3/S2-3 lives here), disappear rules fade fast leaving a few little oscillators, still rules freeze with every starting cell alive and unchanged, and nothing rules die out completely within a few generations. The main view uses contiguous dash-ranges like 3-7 or 6-7; the arrows switch each axis to the split sets, shifting the gap by one — first tab 3,5-7, second tab 3,6-7 — and to every-other sets like 1,3,5,7. Rules that fit no axis shape can be tested with the custom chips below the map. Click any cell to watch that rule run. Full simulator: conway.html.

Method: each rule runs up to 300 generations from a 10×10 random soup in the middle of a bounded 50×50 arena — three different soups, majority vote. Nothing: the population hits zero. Still: the pattern freezes almost immediately with the starting cells intact. Unstable: the blob touches over half the world, stays dense, or never stops churning. Disappear: it settles within ~40 generations with only a few cells left. Stable: everything else — it transforms for a while and settles bounded. Hover any cell for the exact rule; axis labels mark where each set's first number starts.
