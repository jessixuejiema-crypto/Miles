Shrink Run

Jump over the blocks and reach the flag. Each time you finish, you shrink by 1.5×: smaller body, slower run, lower jump.

Before every new size the level tests itself. If the smaller you can't make it, it erases blocks and adds stairs until every size you've been can still finish.

Move: ← → or A D · Jump: ↑ W or Space · Restart: R
